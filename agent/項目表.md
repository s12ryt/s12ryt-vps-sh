## 外部多 IPv6 邊界

- `s12ryt/s12ryt-ipv6` 是面板、代理核心、Web UI、設定與 systemd 服務的唯一來源。
- 本倉庫不含 Go module、面板原始碼、Playwright、面板 Release build 或資源基準。
- `install-ipv6.sh` 只負責支援平台阻擋、解析最新正式 tag、下載同 tag 上游腳本、舊 `/opt/s12ryt-ipv6` 遷移及錯誤恢復。
- 上游部署資料為 `/etc/s12ryt-ipv6`；卸載保留該目錄。
