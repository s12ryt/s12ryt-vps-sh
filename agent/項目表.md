## v1.1.0 Go 與 Web 結構

| 路徑 | 用途 | 主要依賴 |
| --- | --- | --- |
| `go.mod` | Go 面板模組與可重現相依版本 | Go toolchain |
| `cmd/s12ryt-ipv6/` | 面板單一 binary 入口 | `internal/`、嵌入式 Web 資產 |
| `internal/domain/` | 節點、出口模式、拓撲、輪換與設定模型 | Go 標準庫 |
| `internal/store/` | schema 化 root-only JSON、原子寫入與備份 | `internal/domain/` |
| `internal/auth/` | 密碼雜湊、session、CSRF、登入限速與敏感值解鎖 | Go crypto、`internal/store/` |

| `internal/singbox/` | sing-box 七協議設定、TLS transport 與 Reality 設定生成 | `internal/domain/` |
| `internal/importer/` | 遠端 outbound URI、JSON 與 Base64 匯入驗證 | Go 標準庫 |
| `internal/share/` | 本機節點 URI、client JSON、QR payload 與 Base64 訂閱 | Go 標準庫 |
| `internal/routing/` | 新連線出口輪換、健康狀態與週期檢查排程 | Go 標準庫 |
| `internal/network/` | IPv6 探測/生成、地址命令與防火牆計畫 | `internal/domain/`、系統命令介面 |
